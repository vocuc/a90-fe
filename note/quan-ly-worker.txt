==================================================
0. HIỆN TRẠNG (để tham khảo khi thảo luận)
==================================================
Worker = máy nội bộ chạy bằng token, gọi API backend (repo a90.local):
- Tạo ảnh: GET /api/v1/jobs, chỉ nhận job của các tài khoản A51 admin gắn cho worker (imageUsers, nhiều tài khoản).
- Đăng bài: GET /api/v1/publish-jobs, chỉ worker được gắn tài khoản đăng bài của một nền tảng.
- Tạo video: GET /api/v1/video-images, worker được gắn tối đa 1 tài khoản tạo video (videoUser).
- Mỗi lần worker gọi API thì cập nhật last_seen_at.

Trang admin (web, /admin/workers) đang có:
- Danh sách, tạo worker (nhập tên -> sinh token), xem chi tiết.
- Đổi tên, đổi token (token cũ hết hiệu lực ngay), bật / tắt worker.
- Gắn / gỡ tài khoản tạo ảnh, đặt / bỏ tài khoản tạo video.
- Xem lại token (worker tạo sau khi có lưu token mã hoá).

Frontend (a90-fe) chưa có trang nào về worker.

7. ĐÃ CHỐT (2026-11-01)
==================================================
- Chủ shop (có hồ sơ người bán) chỉ XEM worker admin đã gắn cho mình. Thêm / gắn / bật tắt / đổi token vẫn ở trang admin.
- Worker "gắn cho shop" khi có ít nhất 1 chức năng của shop:
    Tạo ảnh: tài khoản shop nằm trong tài khoản tạo ảnh của worker
    Đăng bài: worker giữ tài khoản đăng bài của shop
    Tạo video: worker lấy ảnh tạo video từ tài khoản shop
  Worker đang tắt không hiện.
- Mỗi worker hiện: tên, chức năng, nền tảng + kênh đăng bài (nếu có), online / offline (gọi API trong 5 phút gần
  đây) + lần hoạt động cuối, token (ẩn mặc định, bấm hiện / sao chép; worker cũ chưa lưu token -> "liên hệ admin").
- Lối vào: Công cụ -> Quản lý -> "Quản lý worker" (/seller/workers). Tự tải lại mỗi phút.
