2. TAG SẢN PHẨM
----------------------------------------
Bảng products thêm:
- ai_label        varchar(60) null   nhãn ngắn, vd "Cao gót mũi nhọn đỏ" (Top N in "#k <ai_label>, <lý do>")
- tags            json null           {kieu, got, mau, phong_cach[], dip[]}
- tag_sources     json null           nguồn từng trường: {"ai_label":"ai","kieu":"owner",...} (ai | owner)
- tagged_at       datetime null       lần AI gắn gần nhất
- tagged_image_id bigint null         product_images.id của ảnh bìa AI đã xem (đổi ảnh bìa -> coi là cần gắn lại)

Giá trị (enum, backend kiểm tra, sai -> 422):
- kieu        (1):    cao_got, sandal, bup_be, mule, sneaker, boot, dep, slingback
- got         (1):    bet, thap, vua, cao
- mau         (1-2):  chữ tự do ngắn, vd "do", "kem", "den"
- phong_cach  (1-3):  sang_chanh, nhe_nhang, tre_trung, ca_tinh, basic
- dip         (1-4):  di_lam, di_tiec, tet, hen_ho, di_choi, cafe
- ai_label:   <= 60 ký tự, không emoji, không tên hãng.

Luật ghi:
- AI gửi tag -> backend chỉ ghi trường có nguồn "ai" hoặc chưa có; trường "owner" giữ nguyên (bỏ qua, không lỗi).
- Chủ shop sửa trường nào trên A51 -> nguồn trường đó thành "owner". Chủ shop xoá giá trị -> trả về chưa có (AI gắn lại được).

Frontend (trang Sản phẩm, sửa sản phẩm): khối "Tag (AI)" hiện ai_label + các tag, sửa được (chọn enum), trường do AI
