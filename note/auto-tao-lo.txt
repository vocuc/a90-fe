YÊU CẦU BAN ĐẦU
---------------

- Tạo tính năng quản lý sản phẩm cho phép người dùng tạo sản phẩm gồm các thông tin sau:
+ ảnh sản phẩm, ảnh này là ảnh cung cấp đầu vào của nguyên liệu trong creative
+ hashtag
- Tạo nhóm creative, người dùng sẽ đặt một group ID cho mỗi creative, các creative cùng id là một cặp, id là người dùng tự điền vào.
- Tạo lô tự động mỗi sản phẩm sẽ được tạo lần lượt theo từng nhóm creative luân phiên cho đến hết, mỗi ngày tạo tối đa 10 lô, số lượng tối đa được cấu hình trong admin.


ĐÃ CHỐT
-------

(Cập nhật sau khi đọc trả lời 1-19.)

- Chỉ dùng creative do chính người dùng tạo, trạng thái Đang bán (công khai + riêng tư). Trừ tiền theo giá bán
  hiện tại như người mua khác.
- Sản phẩm: tên (không bắt buộc) + nhiều ảnh, mỗi ảnh liên kết tới một key trường nguyên liệu (người dùng tự gõ key).
  Bỏ hashtag.
- Nhóm creative: thực thể có tên, có N creative, một creative chỉ nằm trong một nhóm.
- Mỗi lô = 1 sản phẩm x các creative của 1 nhóm, mỗi creative 1 ảnh.
- KHÔNG chạy theo lịch, không giới hạn / ngày, không cấu hình admin: người dùng bấm "Tạo tự động" (chỉ có ở
  trang danh sách lô /batches), nhập số lô + công tắc chèn logo -> hệ thống chọn sản phẩm x nhóm, tạo ảnh, trừ tiền.
- Thứ tự (cập nhật 2026-10-29, thay quy tắc câu 17): nhập N lô -> chọn ngẫu nhiên N sản phẩm và N nhóm, ghép lần lượt
  thành N lô. Mỗi sản phẩm / nhóm dùng tối đa 1 lần mỗi lượt bấm; không đủ thì chỉ tạo bằng số ghép được. Cặp không có
  creative dùng được thì đổi sang nhóm chưa dùng khác. Xem trước trả seed, gửi seed khi tạo để tạo đúng các lô đã xem.
  Vẫn lưu số lô tự động đã tạo của từng sản phẩm (chỉ hiển thị, không ảnh hưởng cách chọn).
- Bỏ qua creative (không báo): không Đang bán / bị ẩn; không có trường nào trùng key đã liên kết;
  còn trường bắt buộc không có giá trị (không liên kết, không có mặc định). Mọi creative bị bỏ qua -> không tạo lô,
  không tính lượt, chọn cặp kế tiếp.
- Không đủ tiền: tạo lần lượt tới khi hết tiền thì dừng, báo đã tạo được bao nhiêu lô.
- Đếm lượt: số lần chạy tự động, xoá lô không giảm, lô tạo tay không tính.
- Lô tạo tự động là lô bình thường (source = auto), xem / tạo lại / Đăng TikTok như lô tạo tay.

ĐẶC TẢ API (THEO TRẢ LỜI 1-23)
==============================

Sản phẩm và nhóm chỉ dành cho Creator: đặt dưới /creator (middleware "creator" như GET /creator/creatives).
Sản phẩm / nhóm của người khác -> 404. /image-batches/auto chỉ cần đăng nhập; chưa phải Creator hoặc không có
creative Đang bán -> 422 AUTO_NOTHING_TO_CREATE (frontend báo "Cần có creative Đang bán của bạn", câu 21).

SẢN PHẨM
--------
Product:
{
  "id": 3,
  "name": "Áo thun trắng",          // null được
  "cover_url": "https://...",       // ảnh đầu tiên
  "images": [ { "id": 10, "url": "https://...", "field_key": "product_image" }, ... ],
  "auto_batch_count": 4,            // số lượt chạy tự động (câu 18)
  "created_at": "..."
}

GET    /creator/products?page=&per_page=        mới nhất trước
GET    /creator/products/{id}
POST   /creator/products (multipart)            name?, images[i][file], images[i][field_key] -> 201 { data: Product }
POST   /creator/products/{id} (multipart)       sửa: name?, images[i][id] (giữ ảnh cũ) hoặc images[i][file] (ảnh mới),
                                        images[i][field_key]; ảnh cũ không gửi lại thì xoá -> 200 { data: Product }
DELETE /creator/products/{id}                   lô đã tạo giữ nguyên (product = null) -> 204
Kiểm tra: ít nhất 1 ảnh; field_key bắt buộc, dạng a-z 0-9 _, không trùng trong cùng sản phẩm
(422 errors["images.1.field_key"]); ảnh như trường ảnh của creative (dung lượng, định dạng).

NHÓM CREATIVE
-------------
CreativeGroup:
{
  "id": 5, "name": "Bộ ảnh nền trắng",
  "creatives": [ { "id": 7, "slug": "...", "title": "...", "cover_url": "...", "price_per_image": 2000,
                   "status": "published" }, ... ],
  "created_at": "..."
}

GET    /creator/creative-groups                 cũ nhất trước (đúng thứ tự dùng ở câu 17), không phân trang
POST   /creator/creative-groups                 { name, creative_ids: [] } -> 201 { data: CreativeGroup }
PUT    /creator/creative-groups/{id}            { name, creative_ids: [] } -> 200
DELETE /creator/creative-groups/{id}            -> 204
Kiểm tra: name bắt buộc; creative phải của chính người dùng (mọi trạng thái, lúc chạy chỉ dùng Đang bán);
creative đã ở nhóm khác -> 422 errors["creative_ids.2"] (kèm tên nhóm đang chứa).

TẠO TỰ ĐỘNG
-----------
GET  /image-batches/auto/preview?count=X
  -> { data: { batches: [ AutoPlan ], total_cost, balance } }
     AutoPlan: { product { id, name, cover_url }, group { id, name }, creatives: [ { id, title, price_per_image } ],
                 cost }   // creatives = các creative sẽ tạo, đã bỏ qua creative không hợp lệ
     Ít hơn X phần tử khi không còn cặp nào hợp lệ.

POST /image-batches/auto                { count (>= 1), insert_logo (0|1), idempotency_key (<= 80) }
  -> 201 { data: { batches: [ ImageBatch ], requested: X,
                   stopped: null | "insufficient_credit" | "no_valid_pair",
                   required: 12000 } }   // required: tiền của lô kế tiếp khi stopped = insufficient_credit
  Không tạo được lô nào vì thiếu tiền -> 402 INSUFFICIENT_CREDIT (context.required = tiền lô đầu).
  Không có sản phẩm / nhóm / cặp hợp lệ nào -> 422 AUTO_NOTHING_TO_CREATE.
  Throttle như POST /image-batches; ảnh vào hàng đợi tạo ảnh như lô thường.

Cách chọn (backend, khoá theo người dùng để 2 request không chọn trùng):
  Bảng auto_batch_counts (user_id, product_id, group_id, count).
  Mỗi lô: xếp các cặp theo (tổng count của sản phẩm tăng dần, product.created_at, count của cặp tăng dần,
  group.created_at), lấy cặp đầu tiên có ít nhất 1 creative hợp lệ; không còn cặp -> dừng no_valid_pair.
  Đủ tiền thì tạo lô (trừ tiền cả lô), count + 1; không đủ -> dừng insufficient_credit.

Điền nguyên liệu cho từng creative:
  - Trường ảnh (type image, backend chỉ có loại này) có key trùng field_key của ảnh sản phẩm -> ảnh đó.
  - Trường khác: giá trị mặc định của Creator, không có thì để trống.
  - Còn trường bắt buộc trống -> bỏ qua creative. Nguyên liệu ẩn (hidden_image) tự gửi như thường.

ImageBatch thêm:
  "source": "manual" | "auto",
  "product": { id, name, cover_url } | null,   // null với lô tạo tay hoặc sản phẩm đã xoá
  "group":   { id, name } | null

FRONTEND
--------
- /batches: nút "Tạo tự động" cạnh "Tạo lô" (chỉ ở trang này). Lô tự động có nhãn "Tự động"
  + tên sản phẩm, tên nhóm (danh sách và chi tiết).
- Hộp thoại "Tạo tự động": ô số lô, công tắc chèn logo (như BatchNewPage), danh sách xem trước (creative sẽ tạo
  của từng lô) + tổng tiền + số dư; tạo xong báo "Đã tạo k / X lô" và lý do dừng (hết tiền -> link nạp tiền).
