1b. TRANG "AI VIẾT NỘI DUNG" (/seller/ai-content)
-------------------------------------------------

Tài khoản -> "AI viết nội dung" (chỉ chủ shop, khi bật SOCIAL_AI_CONTENT). Nhân viên dùng chung cài đặt của chủ shop.
Lưu một lần cả trang (bảng shop_ai_settings + shop_hashtag):
  - Độ dài: tiêu đề tối đa 10..90 ký tự (mặc định 90), nội dung tối đa 50..2000 ký tự (mặc định 2000). Prompt dặn AI
    không vượt, backend vẫn cắt cứng theo đúng số này.
  - Bài viết mẫu: tối đa 10 bài { tiêu đề (không bắt buộc), nội dung (bắt buộc) }. AI học giọng văn, cách xưng hô,
    cách trình bày (xuống dòng, emoji), độ dài tương tự; không chép nguyên. Không có bài mẫu: AI viết 2-5 câu.
  - Kho hashtag: tối đa 100, AI chọn tối đa 5 hợp với ảnh. Kho rỗng: bài không có hashtag.


2. LUỒNG
--------

Tạo bài bật AI (POST /social/posts/from-images, ai_content: true):
  - Chỉ có tác dụng khi SOCIAL_AI_CONTENT bật và người dùng không gửi kèm tiêu đề / nội dung / hashtag.
  - Trừ phí ngay trong transaction tạo bài. Không đủ Credit -> 402 INSUFFICIENT_CREDIT, không tạo bài.
  - Bài ở generating ("AI đang viết..."), queue job WriteSocialPostContent gọi Claude (claude-haiku-5-5,
    ANTHROPIC_SOCIAL_MODEL) với 4 ảnh đầu (thumbnail) + tên / mô tả / ngành hàng của các mẫu + cài đặt của shop
    (kho hashtag, bài viết mẫu, số ký tự tối đa).
  - Viết xong -> pending_review với nội dung AI viết.
  - AI lỗi / queue không chạy quá 30 phút (social:sweep) -> pending_review với nội dung mặc định (tên mẫu + hashtag
    của mẫu) và HOÀN phí (ledger social_content_refund).
  - Gửi lại cùng idempotency_key không trừ lần 2.

"Viết lại bằng AI" (POST /social/posts/{id}/ai-content):
  - Chỉ khi bài pending_review (khác -> 409 POST_NOT_EDITABLE). Giới hạn chung với tạo ảnh (throttle generations).
  - Kiểm tra Credit trước (402, không gọi AI), gọi Claude trong request (5-15 giây), chỉ trừ phí khi viết được.
  - AI lỗi -> 503 AI_CONTENT_FAILED "AI chưa viết được nội dung, vui lòng thử lại. Bạn không bị trừ Credit."
  - Tắt tính năng -> 409 AI_CONTENT_DISABLED.
  - Trả { title, content, hashtags, credit_balance }, KHÔNG lưu vào bài: frontend điền vào form, người dùng xem lại
    rồi bấm Đăng. Form đang có nội dung thì hỏi xác nhận trước khi thay.

Kết quả AI được backend chuẩn hoá: tiêu đề / nội dung cắt theo số ký tự shop đặt (trần 90 / 2000 để vừa Instagram 2200
cả dòng hashtag),
bỏ #tag lẫn trong nội dung, hashtag ngoài kho bị bỏ (schema JSON cũng ép enum theo kho), lấy tối đa 5.


3. API
------

POST /social/posts/from-images  thêm ai_content (boolean, không bắt buộc, mặc định false)
SocialPost                      thêm ai_content (boolean)
POST /social/posts/{id}/ai-content -> { data: { title, content, hashtags, credit_balance } }
GET  /creator/ai-content        -> { data: { hashtags: string[], samples: [{ title, content }], title_max, content_max,
                                    product_hashtags: string[], limits: { hashtags: 100, ai_hashtags: 5, samples: 10,
                                    sample_title: 90, sample_content: 4000, title_max: { min, max },
                                    content_max: { min, max } } } }   (chưa lưu: mặc định)
PUT  /creator/ai-content { hashtags, samples, title_max, content_max } -> như trên. Gửi đủ cả trang, rỗng = xoá hết.
     Chỉ chủ shop (middleware creator, khác -> 403). Quy tắc hashtag như Creative.
     422: hashtags.N, samples (quá 10), samples.N.content (bắt buộc), title_max, content_max (ngoài khoảng).
GET  /auth/me                   thêm social_ai: { enabled, price }
Ledger Credit: social_content_charge (trừ), social_content_refund (hoàn), reference social_post #id.

Đã bỏ: API worker GET/POST /api/v1/content-jobs (WorkerContentJobController). Bảng social_content_jobs vẫn dùng
(1 dòng / bài tạo bằng AI, thêm cột charge_amount); cột worker_id / lease_expires_at không dùng nữa.
