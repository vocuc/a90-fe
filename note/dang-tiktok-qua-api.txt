1. TỔNG QUAN
------------

publish_accounts.driver:
  worker  admin gắn (như cũ): worker FlowKit lưu nháp trên TikTok Studio của tài khoản A51.
  api     người dùng tự kết nối: backend giữ token (mã hoá), tự gọi Content Posting API. Không có worker_id.
Một tài khoản A51 có tối đa 1 dòng / nền tảng / driver (TikTok có thể có cả dòng worker và dòng api).

Bấm đăng TikTok thì chọn driver (lưu vào job lúc tạo, đổi kết nối sau đó không ảnh hưởng job cũ):
  - Có dòng api, đang dùng được            -> api.
  - Có dòng api nhưng mất kết nối           -> 409 TIKTOK_NOT_CONNECTED, từ chối CẢ yêu cầu (không tạo job nền tảng nào,
                                              không lưu chỉnh sửa). KHÔNG tự chuyển sang worker (tránh đăng nhầm vào
                                              tài khoản A51).
  - Không có dòng api                       -> worker (như cũ; chưa gắn worker thì job chờ admin gắn).
Huỷ kết nối = xoá dòng api -> lần đăng sau quay lại worker nếu admin đã gắn.

Luồng api:
  Bấm "Đăng bài" chọn TikTok -> job (driver api) queued -> queue job PublishTikTokViaApi
  Queue job chạy             -> processing, tiktok_status publishing: chuẩn bị ảnh, gọi content/init, lưu publish_id
                                (social_publish_jobs.external_id)
  Webhook post.publish.inbox_delivered / complete / publicly_available, hoặc status/fetch SEND_TO_USER_INBOX / PUBLISH_COMPLETE
                             -> job completed, tiktok_status published ("Đã gửi vào hộp thư")
  content/init lỗi / webhook post.publish.failed / status FAILED / quá 60 phút
                             -> job failed, tiktok_status failed. Bài tính lại status như cũ.
Không có link bài (người dùng đăng trong app): post_url luôn null với driver api.

3. KẾT NỐI (OAuth)
------------------

Scope: user.info.basic, user.info.profile (lấy @username), video.upload. Bỏ tích video.upload -> scope_missing.

  [Frontend] bấm "Kết nối TikTok" -> POST /social/tiktok/oauth/authorize { redirect: "/posts/123" } -> { url }
             (trang bài: lưu chỉnh sửa chưa đăng vào sessionStorage để quay về không mất) -> window.location.href = url
  [TikTok]   người dùng đồng ý -> 302 https://a51.vn/mxh/tiktok/author?code=...&state=...  (từ chối: ?error=access_denied)
  [Frontend] trang /mxh/tiktok/author (cần đăng nhập) -> POST /social/tiktok/oauth/callback { code, state, error }
  [Backend]  kiểm tra state (1 lần, 10 phút, ĐÚNG người dùng đã bấm) -> đổi code lấy token -> kiểm tra scope
             -> user/info -> tạo / cập nhật dòng api -> { status: "connected", reason: null, redirect: "/posts/123" }
  [Frontend] hiện "Đã kết nối tài khoản TikTok.", 1,5 giây sau tự về redirect (hoặc bấm "Tiếp tục").
             Lỗi: hiện thông báo + "Quay lại" / "Thử lại".

reason lỗi: access_denied | scope_missing | state_invalid (redirect luôn "/posts") | server_error.
redirect: đường dẫn tương đối bắt đầu bằng "/", sai -> "/posts".
Kết nối lại bằng tài khoản TikTok khác: thay dòng api cũ (thu hồi token cũ).
Còn job api queued / processing: authorize và huỷ kết nối trả 409 TIKTOK_PUBLISHING_IN_PROGRESS.

Token: còn < 5 phút thì làm mới trước khi gọi (khoá theo tài khoản); TikTok báo token sai thì làm mới và thử lại 1 lần,
vẫn sai -> expired. Lệnh tiktok:refresh-tokens hằng ngày 03:30: làm mới refresh token còn < 30 ngày, quá hạn -> expired.
Webhook authorization.removed -> revoked.


4. API NGƯỜI DÙNG (đều cần đăng nhập, trừ webhook)
-------------------------------------------------

4.1 GET /social/accounts   mỗi phần tử thêm:
      "driver": "worker" | "api",
      "connection": { "status": "active" | "expired" | "revoked" | "scope_missing", "avatar_url", "connected_at" }  // chỉ api
    Có cả dòng worker và api của TikTok -> chỉ trả dòng api.
4.2 POST /social/tiktok/oauth/authorize   { redirect } -> 200 { data: { url } }        (10 lần / phút / IP)
4.3 POST /social/tiktok/oauth/callback    { code, state, error } -> 200 { data: { status, reason, redirect } }
4.4 DELETE /social/tiktok/account         thu hồi token ở TikTok, xoá dòng api -> 204 (chưa kết nối vẫn 204)
4.5 POST /social/tiktok/webhook           TikTok gọi, kiểm tra TikTok-Signature (HMAC-SHA256 client_secret, lệch <= 300 giây).
                                          Chữ ký sai 401; không thấy job của publish_id 404 (để TikTok gửi lại).
4.6 SocialPost.platforms.tiktok thêm "driver". error: driver api thì là thông báo CỤ THỂ (mục 6), worker vẫn là thông báo chung.


5. GỬI BÀI (TikTokApiPublisher, queue job PublishTikTokViaApi: 4 lần thử, chờ 30 giây / 2 phút / 5 phút)
----------------------------------------------------------------------------------------------------

1. queued -> processing (hạn 60 phút). Thử lại khi TikTok tạm lỗi: job processing chưa có publish_id thì gửi tiếp.
2. Ảnh: JPG / WEBP giữ nguyên, PNG -> JPG 90. Đặt lên disk s3_tiktok (TIKTOK_MEDIA_BUCKET) ở tiktok/{job_id}/{uuid}.jpg,
   link CÔNG KHAI {TIKTOK_MEDIA_URL}/... (tên miền đã xác minh với TikTok). Xoá thư mục khi job có kết quả.
3. content/init: { post_info: { title, description } (rỗng thì bỏ), source_info: { PULL_FROM_URL, photo_cover_index 0,
   photo_images }, post_mode: MEDIA_UPLOAD, media_type: PHOTO }.
4. Lỗi: mạng / 5xx / rate_limit_exceeded / internal_error -> queue thử lại, hết lượt -> TIKTOK_UNAVAILABLE.
   scope_not_authorized / mất token -> TIKTOK_NOT_CONNECTED (kết nối chuyển expired). Lỗi khác -> failed ngay.
5. social:sweep (mỗi phút): job api processing có publish_id, chưa hỏi trong 5 phút -> status/fetch; sau đó job quá
   60 phút -> TIKTOK_TIMEOUT. Webhook và status/fetch cùng báo thì chỉ đổi trạng thái 1 lần.

Queue: QUEUE_CONNECTION=database, cần chạy php artisan queue:work (như job đọc ảnh GHN).
